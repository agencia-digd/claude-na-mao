// o que é isso

Um kit pronto pra você sair usando

O Claude na Mão empacota o melhor do setup que a Dani usa todo dia, sem nada do que é específico da agência dela. Você instala uma vez, e a partir daí seu Claude Code já vem com personalidade direta, atalhos práticos e skills especializadas pra escrever copy, montar conteúdo de Instagram, editar vídeo, ler email, criar landing page e mais.

Pra começar você precisa: Mac com terminal, plano Pro da Anthropic, e ~15 minutos com a Dani do seu lado pra primeira instalação.
// instalação

5 passos do zero ao primeiro "oi Claude"

Instala o Node e o Claude Code

Abra o Terminal (Cmd+Espaço, digite "Terminal"). Cola e dá Enter:

brew install node tmux
npm install -g @anthropic-ai/claude-code

Se não tiver brew, a Dani te ajuda — uma linha só.

Faz login com seu plano Pro

No Terminal:

claude login

Abre o navegador, você loga na sua conta Anthropic, volta pro Terminal e tá conectado.

Baixa o kit Claude na Mão

git clone https://github.com/agencia-digd/claude-na-mao ~/claude-na-mao
cd ~/claude-na-mao
./install.sh

O script copia as skills, agentes, configurações e o CLAUDE.md pra ~/.claude/. Idempotente — pode rodar de novo sem quebrar nada.

Abre uma sessão tmux

tmux mantém o Claude vivo mesmo se você fechar o Terminal sem querer.

tmux new -s claude
claude

Pra desconectar sem matar: Ctrl+B depois D. Pra voltar: tmux attach -t claude.

Diz oi

No prompt do Claude:

oi! lista as skills e agentes que você tem disponíveis

Se ele responder com a lista, deu certo. Bora explorar.

Como ele lembra de você

Diferente do ChatGPT, o Claude Code realmente lembra entre sessões — sem você precisar repetir contexto toda vez.

CLAUDE.md
Suas instruções permanentes. Quem você é, como gosta que ele responda, o que NÃO fazer. Lê toda sessão.
Auto Memory
Anotações que ele salva sozinho conforme aprende suas preferências, projetos, pessoas. Em ~/.claude/projects/.../memory/.
Sessão viva
Dentro de uma conversa, ele lembra de tudo até você fechar. Use tmux pra manter a sessão viva por dias.
O que você NÃO tem ainda (e tá tudo bem): busca semântica de "lembra quando conversamos sobre X meses atrás". Isso requer um banco vetorial num servidor — roadmap pro futuro, quando você tiver volume.
// quando você crescer

Roadmap de evolução

Comece simples. Ative cada peça quando sentir que precisa — não antes.

📍 AGORA

Dia 1 ao 30 — uso diário

Use as 15 skills e 5 agentes. Ajuste o CLAUDE.md conforme descobre o que funciona pra você. Deixe a Auto Memory acumular contexto.

⏭ MÊS 2-3

Skills personalizadas

Quando perceber que faz a mesma sequência de prompts toda semana — vira skill. Bora codar a primeira juntas: copia uma das 15 como template, adapta.

⏭ MÊS 3-6

MCPs (extensões com superpoderes)

MCPs ligam o Claude a serviços externos com tools dedicadas — exemplos: Google Workspace turbinado, Linear, Slack, sua própria API. Instala um por vez.

⏭ QUANDO ENGATAR

Memória semântica local

Se a Auto Memory não bastar (você quer "lembra do que falamos sobre X em fevereiro"), monta um banco vetorial local no Mac com SQLite + sentence-transformers. Sem custo extra. Roda offline.

⏭ AVANÇADO

Bridges WhatsApp/Telegram

Pra falar com seu Claude do celular como a Dani faz. Requer servidor sempre-ligado (~R$30/mês VPS). Repo separado, instalação guiada quando você quiser.

⏭ MULTI-MÁQUINA

Sync via Git privado

Quando tiver Claude no Mac do trabalho E no de casa, commitar ~/.claude/projects/.../memory/ num repo privado. Memória te segue.
